## 📊 Project Overview

An interactive **Zomato Data Analysis Dashboard** built in **Microsoft Power BI** to analyze restaurant performance, orders, revenue, customers, payment methods, cuisines, and delivery performance.

The project started with an **Excel dataset**, which was imported into Power BI, transformed and cleaned using **Power Query**, and then loaded into the Power BI data model. DAX measures were created to build dynamic KPIs and visualizations.

---

## 🛠️ Tools Used

* **Excel** – Data source
* **Power BI** – Dashboard & visualization
* **Power Query** – Data cleaning and transformation
* **DAX** – Measures and KPIs

## 📌 Key KPIs

* 💰 **Total Revenue**
* 🛍️ **Total Orders**
* 💵 **Average Order Value (AOV)**
* ❌ **Cancellation Rate**
* 🚚 **Delivery Rate**

These KPIs dynamically respond to the dashboard filters.

---

## 📊 Dashboard Visuals

### 🗺️ Revenue by City

A map showing revenue distribution across different cities.

### 🏆 Top 5 Restaurants by Revenue

A bar chart highlighting the top-performing restaurants based on revenue.

### 📈 Revenue & Orders Trend

A combination chart showing how revenue and order volume change over time.

### 💳 Orders by Payment Mode

A donut chart showing the distribution of orders across:

* Card
* Cash
* UPI
* Wallet

### 🎛️ Interactive Slicers

Users can filter the dashboard using:

* Order Status
* Cuisine
* Customer Acquisition Channel

---

## 💡 Custom Tooltips

The dashboard includes **two custom tooltip pages** to provide additional information without leaving the main dashboard.

### Tooltip 1

Displays:

* Total Orders
* Rating Information
* Total Revenue

### Tooltip 2

Displays a **Cuisine vs Total Orders** chart to provide additional cuisine-level insights.
